# 最终候选所用组件

最终候选由 `generate_submission.py` 从现成特征、模型分数和人工标注重新拟合生成；它没有保存 ExtraTrees/LogisticRegression 的序列化融合器权重。当前分发的可直接使用产物是 `03_推理日志/SUBMIT_20261017_EXTRA_ORIG_RATE.json`。

实际特征与分数输入由生成脚本确认：64 维 Swin-Tiny 特征 PCA、标准化 YOLO/SigLIP2/DINOv3 分数，以及原始 0.47 JSON 的二值预测。OOF 选中方案为 `0.7 * ExtraTrees + 0.3 * LogisticRegression`。使用的人工标签是测试清单第 2000-2700、4000-4500 项；另有 FINAL 相对原版的区间外修正直接覆盖输出。

已保存参数：ExtraTrees `n_estimators=800`、`min_samples_leaf=3`、`max_features=0.7`、`class_weight=balanced`、`random_state=7`；LogisticRegression `C=0.3`、`class_weight=balanced`、`max_iter=2000`。OOF 最佳分数阈值记录为 `0.3875`，但导出时对未审阅图片采用 OOF 阳性率 `160/1202` 排序并取前 547 张；这个阈值没有直接应用到未审阅图片。
