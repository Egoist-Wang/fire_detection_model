# Third-Party Components

- PyTorch: tensor runtime and training
- Ultralytics: YOLO training and inference
- timm: DINOv3 model loading and transforms
- Hugging Face Hub: official DINOv3 checkpoint distribution

The repository stores only the DINOv3 classifier head. The frozen DINOv3 backbone is
resolved by its official model identifier and is not copied from the old fire project.
